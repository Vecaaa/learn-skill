# learn — 自适应个人教学系统

一个让 Claude 教你任何东西的 skill。它会记住你已经会什么、你在哪里卡过、
以及什么样的讲法对你有效，用得越久越贴合你。

> 想改这个 skill？看 [CLAUDE.md](CLAUDE.md)，那里有完整的架构和设计决策记录。

---

## 它解决什么问题

直接问 AI 学东西有几个固定的失败模式：

| 问题 | 这个 skill 的应对 |
|---|---|
| 一次讲一大堆，听着都懂，合上就忘 | 单次 ≤1 个知识点，讲完立刻出题 |
| 问"懂了吗"，你说"懂了"，其实没懂 | 禁止问"懂了吗"，改成让你**做** |
| 每次都从零开始，不知道你会什么 | 持久化知识库，跨会话记住掌握状态 |
| 讲的东西建立在你早就忘了的前置上 | 开讲前用一道题探一下前置 |
| 卡住了只会把原话换个说法重讲 | 五级降维梯，先定位卡点再降维 |
| 反馈过的问题下次照犯 | 教学策略进化，带证据门槛 |

## 快速开始

对 Claude 说任意一句：

- 「教我 Rust 的所有权」
- 「我想系统学一下线性代数，为了看懂机器学习论文」
- 「闭包我一直没搞明白，讲讲」
- 「我忘了之前学的那个什么映射，复习一下」

第一次使用时它会问你四个问题（学它干什么 / 目标深度 / 可用时间 / 已有基础），
答完存进档案，之后不再重复问。

想看自己的知识库：

```bash
python3 ~/.claude/skills/learn/scripts/learndb.py status
```

生成可读快照（`~/.claude/learning/knowledge.md`）：

```bash
python3 ~/.claude/skills/learn/scripts/learndb.py export
```

## 核心概念：知识原子（atom）

整个系统围绕一个东西组织：**atom = 能被单独出一道题检验的最小知识点**。

判定标准很实用：**能不能立刻为它写出一道题？**写不出来说明太大，得拆。

- "React" ❌ 太大
- "useEffect 的依赖数组为什么会导致无限循环" ✅ 刚好

教学是按依赖顺序推进 atom，知识库存的是 atom 的掌握状态，
学习路线是 atom 的依赖图，自进化记的是"哪类 atom 用什么教法有效"。
四个模块共用一个对象，所以不会各说各话。

## 掌握度是分级的

| 级别 | 含义 | 怎么证明 |
|---|---|---|
| 0 未学 | — | — |
| 1 见过 | 能复述定义 | 背下来也能过 |
| 2 能复述 | 能判断对错 | 有猜对概率 |
| 3 能应用 | 能预测结果、能找错 | 日常检验主力 |
| **4 能迁移** | **换个场景也会用** | **唯一算真掌握的** |

只有"迁移到新情境"的题通过，才会被标记为掌握。这条规则是整个知识库
不虚高的关键——虚高的掌握度会让系统跳过本该复习的内容。

同时系统给每个知识点估一个**回忆概率**（按遗忘曲线随时间衰减），
用来判断"这个前置是不是该在开讲前确认一下"。

## 卡住时会发生什么

不是把刚才的话换个说法重讲一遍。是**先定位再降维**：

1. **定位** —— "这句话里第一个让你卡住的词是哪个？"
2. **具体化** —— 换成玩具规模的实例，真实数字、真实代码
3. **类比** —— 并且会明确告诉你这个类比在哪里失效
4. **拆前置** —— 卡点其实是缺另一个知识点，就先补那个
5. **换表征** —— 图 / 时间线 / 伪代码 / 物理直觉

降维讲完会**回到原难度重测一次**。否则你会停在类比层还以为自己懂了，
这比没学更糟——它会污染后面所有依赖它的内容。

同一个点连续 3 次答错，系统会标记止损，转去补前置或换个时间，不硬磨。

## 复习：只在你开口时

**没有主动提醒，没有课前热身考试。**你说「我忘了 X」「复习一下 Y」时才启动，
而且支持模糊说法（"那个什么栈的东西"也能定位到）。

复习流程是**先测后讲**：先确认你到底忘了多少，避免从头重讲浪费时间。

唯一的例外是**前置探针**——教新东西之前，如果它依赖的知识点你没学扎实、
或者估计已经开始忘了，会先用**一道题**确认。这是教学决策不是复习课：
只探直接前置、不往上追溯、一题定生死。

## 跨月的大目标：会自动做路线图，且会记住

对「我想学一年，自己做出一个 GPT」这类宽泛的大目标，会：

1. 先帮你把目标澄清成具体的成功标准（字面意义的 GPT-3 需要千万美元级算力，
   真正可达成的对标通常是复现 GPT-2 规模、理解怎么再往上扩展——这种拆穿会
   在第一步就发生，不会等你自己发现目标不现实）
2. 检索时优先找现成的阶梯式项目课程（比如 Karpathy 的
   micrograd→makemore→nanoGPT 路径），有的话直接采纳，不从零现编
3. 切成里程碑（phase），**只把当前阶段和下一阶段展开到具体细节**，
   更远的阶段先只给阶段名和"到那一步你应该能做什么"——因为提前设计的远期内容
   大概率会被你在前面学到的东西推翻，属于白做
4. 每个阶段配 1-2 个巩固项目，**创建时会明确告诉你哪部分已经帮你写好、
   哪一小块需要你自己设计和实现**，项目体量控制在一到几次学习会话内，
   规模超了就砍范围而不是拖时间
5. 每个阶段结束会做复盘：实际花了多久 vs 之前估计的，用这个比例重新校准
   后面阶段的时间估计——不是死守最初拍的"一年四个阶段"

**这套路线图是真的存进数据库的，不是聊天里说说就没了。**任何时候都可以说
"给我看看路线图"，会查出真实进度，而不是凭对话记忆现编一份。

## 代码 / 神经网络与机器学习 / 读论文有专项套路

这三个领域各有一套研究支持的具体教法（`references/domains.md`），教到这类内容时
会自动用上，不用你特意要求：

- **代码**：读代码先于写代码（预测→运行→调查→修改→自己写），照专家的路径
  自顶向下讲（先接口后实现），追踪执行过程用变量表而不是口头讲
- **神经网络/机器学习**：代码和直觉优先于数学推导，先跑通一个完整模型再逐层剥开，
  能用可视化就不用纯文字
- **读论文**：三遍读法（先看题目摘要图表判断值不值得读，再抓内容，最后逐字读），
  精读后的检验是"去掉这个假设结果会怎样"而不是"这篇讲了什么"

## 数据存在哪

```
~/.claude/learning/
├── learn.db          # SQLite，唯一真源
├── knowledge.md      # 可读快照（export 生成，适合 git 备份）
├── sources.jsonl     # 站点注册表，不含任何凭据
└── backups/          # 自动快照，保留最近 20 份
```

**全部在本机。**没有任何东西上传。想备份就把 `~/.claude/learning/` 放进 git。

关于登录：这个 skill **不会索取你的账号密码**。遇到需要登录的资料，
它会请你自己登录一次（登录态之后会保留），或者请你把内容粘贴过来。

## 文件结构

```
~/.claude/skills/learn/
├── SKILL.md                     # 主循环 + 硬性约束（Claude 每次触发都会读）
├── README.md                    # 你正在看的这份
├── CLAUDE.md                    # 改这个 skill 时的入口文档
├── references/                  # 按需加载，不占默认上下文
│   ├── pedagogy.md              # 讲解协议、降维梯、检验题设计
│   ├── research.md              # 检索策略、防幻觉、登录处理
│   ├── planning.md              # 跨月大目标的阶段规划与滚动校准
│   ├── domains.md               # 代码/神经网络与机器学习/读论文的专项套路
│   ├── memory-schema.md         # 数据库结构、遗忘模型、命令全表
│   └── evolution.md             # 三层进化、证据门槛、防膨胀
└── scripts/
    └── learndb.py               # 所有数据库操作的唯一入口
```

数据出问题时（比如觉得复习提示不对劲），可以自己跑一下体检：

```bash
python3 ~/.claude/skills/learn/scripts/learndb.py doctor
```

## 想改它

用实际使用体验来改是对的——这个 skill 的很多参数（探针阈值、证据门槛、
单次篇幅上限）都是拍出来的初值，需要真实使用来校准。

改之前让 Claude 读 [CLAUDE.md](CLAUDE.md)，里面记了每个设计决策**为什么**
是现在这样，以及哪些是可调参数、哪些动了会连锁出问题。
